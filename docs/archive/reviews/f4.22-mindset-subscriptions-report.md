# f4.22 Money Mindset Subscriptions list, implementation report

Founder decision (2026-08-15): the Subscription path should be backed by a NEW
subscriptions list the person maintains inside Money Mindset (chosen over
reusing the app's recurring bills). This phase delivers that foundation and its
first visible surface.

## What changed

- New flutter/lib/money/mindset_subscriptions.dart: the Subscription model and
  the overview engine. Each subscription has a price and a monthly or annual
  cycle; the overview normalizes every annual price to a monthly figure and sets
  annualTotal to exactly monthlyTotal x 12, so the two figures can never disagree
  on screen. Defensive on read: junk amounts, unknown cycles, and non-map rows
  are coerced or dropped, never a divide-by-zero or NaN.
- lib/data/backup.dart: settings.mindsetSubscriptions as a CONDITIONAL key
  (present only when the cleaned list is non-empty), with a new _subscriptionList
  cleaner modeled on _paluwaganList (stable de-duplicated id, non-empty name,
  non-negative finite amount, coerced cycle, conditional emoji).
- lib/data/store.dart: getter mindsetSubscriptions plus add / patch / remove,
  mirroring the mindsetWaiting and mindsetDecisions passthrough pattern. patch
  coerces the two money-shaped fields for defense in depth (data-migration
  reviewer's nice-to-have).
- lib/screens/mindset_subscriptions_screen.dart: the Subscriptions screen, an
  overview header (count, monthly total, and the yearly figure) over a list with
  add / edit / delete, and an add/edit bottom sheet (name, price, monthly or
  yearly, optional emoji).
- lib/screens/mindset_flow.dart: the Subscription type in Step 1 now shows a peek
  card (count and monthly total) that opens the screen.
- lib/main.dart: stamp f4.22.

## Money and data

NEW STORED DATA, but ADDITIVE with NO migration and NO schemaVersion bump.
settings.mindsetSubscriptions is a conditional key exactly like paluwagans and
netWorthHistory, so the RN-generated golden key-set contract holds. READ-ONLY
money in the Salapify sense: a subscription records what the person pays
elsewhere and never moves a Salapify balance; no transaction is created.

The data-migration-reviewer (mandatory for a backup.dart change) returned PASS
and EXECUTED the golden key-set tests plus adversarial probes (triple-duplicate
ids de-duped, NaN/Infinity/string amounts never taint the total, unknown per-row
fields survive sanitize, an RN-style settings blob never gains the key), rather
than only reading them.
