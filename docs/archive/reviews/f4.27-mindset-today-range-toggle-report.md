# f4.27 Dashboard Today / 30 days toggle, implementation report

Shelf item 2 of 3 from the founder's Money Mindset shelf: a rolling-window
option on the dashboard summary.

## What changed

- flutter/lib/money/mindset_decisions.dart: new pure helper mindsetRangeStats,
  the same four figures as mindsetTodayStats over a rolling last-N-days window.
- lib/screens/mindset_today.dart: the summary is now a small stateful section
  with a Today / 30 days segmented toggle. Today stays the default; 30 days is an
  added view. The grid and its labels are unchanged (they were already
  window-agnostic).
- lib/main.dart: stamp f4.27.

## Money and data

READ-ONLY: every figure is read from settings.mindsetDecisions; no balance is
touched, no storage or schema change. Enhance-not-regress: Today remains the
default and its numbers are identical to before; 30 days is purely additive, the
same pattern the Sweldo Timeline used (grew inside an existing screen, old view
kept as default).

## Validation

- flutter analyze: 0 issues. Full suite green.
- New vectors (mindset_range_stats_test): days:1 matches today-only, days:30
  includes today..29 days ago and excludes 30+ and future-dated rows, junk safe.
- New widget test (mindset_today_test): the toggle changes the title and widens
  the counted window (₱500 today to ₱1,300 across 30 days).
- Rendered Mindset Today dark and looked.
