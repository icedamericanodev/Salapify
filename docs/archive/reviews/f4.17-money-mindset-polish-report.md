# f4.17 Money Mindset device-feedback polish, implementation report

Founder direction (2026-08-14): after installing f4.16 on the phone, the
founder reported three things to fix on the shipped Money Mindset flow. This is
a small polish pass on top of the f4.16 flagship, not a new feature.

## Scope

Three fixes reported from real-device use:
1. "When I click Done nothing happened." (Step 4's Done button was inert.)
2. "The text box or oval makes the digits narrower, is it appealing?" (The
   input fields drew an oval around the value that squeezed the digits.)
3. "Is there a way that I dont need to go through each step to see the overview
   or last 30 days?" (No shortcut to the reflection view.)

## What changed

- flutter/lib/screens/mindset_flow.dart
  - Done now closes the flow. On the last step the primary nav button had no
    forward target, so it did nothing. It now calls Navigator.maybePop, so Done
    pops the flow the same way the close button does.
  - Cleaner input fields. The item and amount TextFields were inheriting the
    app's inputDecorationTheme, which draws a rounded OutlineInputBorder INSIDE
    the field. Sitting inside the field's own rounded container, that inner
    border read as an oval that narrowed the digits on the phone. A shared
    _bareInput helper nulls every border state (border, enabled, focused, error,
    focusedError, disabled), sets isCollapsed, filled false, and zero content
    padding, so the value uses the full width of the field's single rounded
    container.
  - My 30 days shortcut. A new AppBar text action jumps straight to Step 4, the
    reflection overview, without walking Context to Impact to Decision first.
    It is hidden on Step 4 itself (you are already there).
- flutter/lib/main.dart: stamp f4.17.

## Money and data

No money math, sign, currency, precision, rounding, schema, or stored data
changed. The flow is still read-only against the golden-locked engines, and the
only writes remain the existing tested store paths (addWin, addMindsetWaitingItem
plus Reminders.reschedule, logMindsetCheck). These are presentation-only fixes.
