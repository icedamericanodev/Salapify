# f4.37 Money Mindset Impact-step redesign

Stamp: f4.37
Branch: claude/execute-this-4is90d
Type: presentation only, ships over the air (Shorebird patch)

## Scope

Founder-directed redesign of the Money Mindset "Impact" step (Step 2 of 4) from a
supplied mockup. Two founder instructions drove it:
- "Build the best from the choices" (combine the mockup with the shipped app).
- "I do not get what Dips mean."

## What changed

Presentation only. No money math, no data, no schema, no write path.

1. Decision Score card (adopts the mockup). The centered gauge + big heading +
   subcopy + link stack is replaced by one compact hero card: kicker
   "DECISION SCORE", then the gauge beside the verdict word, a one-line reason, and
   the "How we score this" link. Designed with the flutter-ux-craftsman:
   - The hero shell uses the primary tint (0.08 fill, 0.25 border, Radii.hero,
     Insets.hero) for ALL bands, matching the other Step-2 cards. The band color
     lives only on the verdict word and the gauge number, so a red verdict never
     sits on a red card.
   - A LayoutBuilder stacks the gauge above the words when the inner width is under
     272px or the text scale is above 1.3x, so nothing clips at 320dp or 2.0x. The
     gauge is 128 in the row, 120 stacked.

2. Plain-language "Money for bills" (fixes "Dips"). Verified with a financial-coach
   so the wording stays truthful to the engine (reservedShortfall is how much a buy
   would fall short of the money set aside for bills and debt due before payday; it
   is not money already spent, and it is not a fee):
   - Row label "Bills and debt" -> "Money for bills".
   - Good state "No dip" -> "Bills covered".
   - Bad state "Dips PHPX" -> "PHPX short".
   - The "How we score this" explainer row updated to match the new verb.
   - A small warning glyph now sits beside the short value, so the alert is not
     carried by color alone (WCAG 1.4.1, red-green safe).

3. Goal bars relabeled (mockup). "Now" -> "Before purchase", "If you buy this" ->
   "After purchase".

## What did NOT change

- No money value, sign, currency, precision, rounding, account relationship,
  transaction classification, calculation, reconciliation, schema, or stored data.
  The score, band, buffer, income share, reserved shortfall and goal delay are the
  same engine outputs as f4.36.
- The 3-signal transparency ("What this looks at") is preserved, not collapsed into
  the mockup's single buffer card, so no shipped detail was regressed.
- The flow stays read-only money; no write path touched.
- Deliberately NOT done, founder-gated:
  - promoting the cash buffer to its own status-pill card (the mockup's third card),
  - remembering the last-chosen goal in the goal picker,
  - an always-on "Comparing against: <goal>" line when only one goal exists.
