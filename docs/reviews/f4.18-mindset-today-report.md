# f4.18 Mindset Today dashboard, implementation report

Founder direction (2026-08-14), with a supplied "Mindset Today" mockup: move the
"my 30 days" overview into a dashboard that becomes the landing screen for Money
mindset, with a summary of the person's decisions and a recent-decisions list.

Before building, the restructure was brainstormed with the founder and three
founder-gated calls were put to them and approved:
- add a small, data-safe decision history (so the list can show real rows): YES;
- add an optional note when logging a decision: YES;
- keep Money mindset in the Menu for now (not promoted to a bottom-nav tab): YES.

## Scope

A new dashboard landing (MindsetTodayScreen) reached from the Menu:
- a calm header (the Pan meditating cup) with a "+ Log a Decision" button that
  launches the existing four-step flow;
- "Today's summary": Decisions made, Purchases made, Purchases avoided, and
  Money avoided (today-scoped);
- "Recent decisions": the latest logged decisions with item, optional note,
  amount, an outcome badge, and when, plus "View all" to the full history.

## What changed

- New flutter/lib/money/mindset_decisions.dart: pure helpers over the decision
  history (today counts and the money-avoided sum, newest-first ordering with a
  junk row sorted last, the "when" label, the flow-outcome mapping, labels).
- New lib/widgets/mindset_decision_tile.dart: one decision row, shared by the
  dashboard and the full list.
- New lib/screens/mindset_today.dart (dashboard) and
  lib/screens/mindset_decisions_list.dart (the "View all" full history).
- lib/data/store.dart: addMindsetDecision plus the mindsetDecisions getter.
- lib/screens/mindset_flow.dart: an optional note field on the decision result,
  and one decision record written per finish (alongside the existing win /
  waiting / check writes).
- lib/screens/menu.dart: the Money mindset tile now opens MindsetTodayScreen.
- lib/main.dart: stamp f4.18.

## Money and data

DATA change, founder-approved, additive and data-safe: a new
settings.mindsetDecisions passthrough list, the same conditional pattern
mindsetWaiting and mindsetChecks already use. It is absent on every RN fixture
(only written when a decision is logged), so the golden key-set contract holds,
and it is preserved by sanitizeData's {...settings} spread with NO backup.dart
change and NO migration. No schema version bump.

READ-ONLY money, unchanged: the amount on a decision is the person's own Step 1
estimate, shown back to them and summed into "money avoided" for the ones they
skipped. It is never a transaction and moves no balance. The journey test proves
the transaction count is unchanged across a full log-a-decision flow.

## Validation

- flutter analyze: 0 issues. Full local suite green.
- New mindset_decisions_test: today counts and the money-avoided sum (an avoided
  buy adds, a purchased or waiting buy never does, yesterday never counts toward
  today), newest-first ordering with a timestamp-less row last, the 12-hour
  "when" label (today time / Yesterday / date), and the flow-outcome mapping.
- New mindset_today_test: a logged decision persists and round-trips through a
  reload (which runs sanitizeData, proving the passthrough), a blank note is
  dropped, the key is absent when empty (golden key-set), the dashboard summary
  reads today, the empty state, and a full journey (log a decision from the
  dashboard, it lands in Recent decisions, no balance moves).
- Break-then-prove on the journey guard: disabled the decision write, watched
  "Expected: <1> Actual: <0>" fail, restored after the run reported.
- Both new screens added to the readability sweep (swept, not exempted).
- Rendered the dashboard dark and light and reviewed; surfaced to the founder.

## Risks

Low to moderate. New primary screen and a menu swap, plus an additive data key.
Money stays read-only, the new key follows the proven conditional-passthrough
pattern with no migration, and the write-through and read-only guarantees are
covered by tests including a full journey.
